
# QA Portfolio — Daria Gavrish

## About Me

Junior QA Engineer with hands-on experience in manual and automated testing of web applications.

I have practical experience in functional, regression, UI, validation, responsive, API, and database testing.

I create and execute test documentation, report defects, test REST APIs using Postman, and write SQL queries for database testing.

I also develop automated tests using **Cypress with JavaScript** and **Playwright with TypeScript**.

My automation experience includes Page Object Model (POM), custom commands, fixtures, authentication, API testing, network mocking, and cross-browser testing.

I have practical experience configuring **Docker and GitHub Actions for Continuous Integration (CI)** to run automated tests.
