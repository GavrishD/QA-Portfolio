# Help for Kittens

## Project Overview

Help for Kittens is a web application created to support animal shelters through donations and virtual card management.

## Role

## Project Scope

- Account Management
- Add Card
- Replenishment
- Delete Card
- Donations
- Mobile Version

## Testing Activities

- Bug Reporting
