# Database Testing

This section contains SQL queries created as part of the **Hillel Auto IT** project.

The queries were used to work with application database data related to users, cars, car brands, models, expenses, settings, and instructions.

## Tools

- MySQL
- MySQL Workbench

## SQL Skills Demonstrated

- SELECT queries
- Data filtering with WHERE
- Sorting with ORDER BY
- LIKE, IN and BETWEEN operators
- Aggregate functions: COUNT, AVG, MIN, MAX, SUM
- JOIN operations
- GROUP BY and HAVING
- Subqueries
- Working with date functions

## Query Structure

The SQL queries are organized into the following sections:

1. Basic Queries and Filtering
2. Aggregate Functions
3. JOIN Queries
4. Grouping and Aggregation
5. Subqueries
